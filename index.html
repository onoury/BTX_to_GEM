How to run & conversion notes

Keep index.html, styles.css, scripts.js and pyscripts.py in one folder. Serve that folder with any static web server. For a local preview, run python -m http.server 8000 there, then open http://localhost:8000. Internet access is needed to load Pyodide and Plotly.

Geometry uses the original Python decoding, placement, healing, snapping, scaling, extrusion and GEM writer. Locations and grid presets come from that script. Custom grid spacing is measured on the drawing page: inches × 72 or centimetres ÷ 2.54 × 72 gives points. Custom page scale uses 1:N (for example, 1″ = 10 ft means N = 120). Floor offsets are (floor − 1) × height; the default is 9 ft. The export contains no openings. The displayed area sums paired room polygons; it is not a union or overlap check.

CSV rows map to polygons in order. “Room #” is informational. The 3D preview updates automatically after uploads and edits. Unpaired polygons are shown in grey at ground level until assigned a floor, and are excluded from export. Confirmation is required only to create and download a GEM file. Changed inputs invalidate the previous downloadable GEM.
